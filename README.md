A 4 KB pure-Python chess engine: alpha-beta search with quiescence, a fixed node budget per move (no clock, so replays match), and incremental material plus piece-square evaluation.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
